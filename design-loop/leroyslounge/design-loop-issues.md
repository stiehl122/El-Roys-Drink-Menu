# Leroy's Lounge Design Loop Issues

## Pass 1 audit

1. The desktop route still feels under-composed, especially on the drinks menu. Categories and items float in a very large lined field with long stretches of empty canvas, so the page reads as sparse rather than atmospheric.
2. The section rhythm is too weak on desktop. Headings, item lists, and the footer all sit on the same slat field without enough framing, which makes the page feel like text placed on a background instead of a finished board.
3. The mobile header action cluster still behaves like desktop controls squeezed into a narrow column. The logo, menu toggle, jump link, dropdown trigger, and user affordances compete for the same small strip instead of forming a clear mobile-native hierarchy.
4. Food rows with sold-out treatment are still too muddy at narrow widths. The strike-through text, diagonal `Sold Out` badge, and price block all compete inside the same tight side column, which makes the 86'd state feel messy instead of intentional.
5. The footer hierarchy is too faint for how important the information is. Last-updated text, version metadata, and staff actions all sink into the lower-right corner as small utility text instead of landing like a designed closing moment.
