# Leroy's Lounge Design Loop Issues

## Pass 1 audit

1. The mobile header action cluster still behaves like desktop controls squeezed into a narrow strip. The logo, menu toggle, route jump, and swap trigger all fight for width instead of landing as a clear mobile-native control hierarchy.
2. Food rows with sold-out treatment are still too muddy at narrow widths. The strike-through text, diagonal `Sold Out` badge, and price block all compete inside the same tight side column, which makes the 86'd state feel messy instead of intentional.
3. The footer hierarchy is too faint for how important the information is. Last-updated text, version metadata, and staff actions still sink into the lower edge as small utility text instead of landing like a designed closing moment.
