# Leroy's Lounge Design Loop Issues

## Pass 1 audit

1. The desktop route feels under-composed, especially on the drinks menu. Categories and items float in a very large lined field with long stretches of empty canvas, so the page reads as sparse rather than atmospheric.
2. The mobile header action cluster feels like desktop controls squeezed into a narrow column. The small logo, stacked utility buttons, and separate user chip compete for attention instead of forming a clear mobile-native control rhythm.
3. Food rows with sold-out treatment get muddy on mobile. The strike-through text, diagonal `Sold Out` badge, and right-aligned prices crowd each other, which makes the 86'd state feel messy instead of intentional.
4. The manager/admin flyout on mobile opens directly over the page content and can intercept taps meant for nearby controls. With the flyout open, the adjacent user menu becomes hard to reach because the dropdown overlaps that part of the header.
