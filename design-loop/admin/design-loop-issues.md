# Admin Design Loop Issues

## Pass 1 audit

1. The mobile admin shell spends too much of the first screen on the converted sidebar. `Admin Console`, the section tabs, the restaurant summary line, and `Return to menu view` occupy a large dark slab before the actual work begins, so the page feels front-loaded and slower to enter than it should.
2. On mobile light mode, `Return to menu view` nearly disappears inside the sidebar block because its contrast is too weak against the surrounding surface.
3. The mobile user-menu popover collides with the top edge of the first content card instead of feeling anchored to a protected header zone. It remains usable, but the overlap makes the interface feel cramped and improvised.
4. The desktop layout leaves too much dead vertical space in the left rail once the main cards begin. The rail feels visually detached from the active work area instead of supporting it.
