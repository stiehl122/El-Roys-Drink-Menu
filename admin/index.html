Menu-level delivery toggles

Toggle which channels fire when you send a menu update for the selected menu.

Go to dev.groupme.com → Bots → Create Bot. Set the callback URL to your Vercel deployment URL. Copy the Bot ID and add it as a Vercel environment variable:

GROUPME_BOT_ID

Sign up at twilio.com and buy a phone number. Add these Vercel environment variables:

TWILIO_ACCOUNT_SID
TWILIO_AUTH_TOKEN
TWILIO_FROM_NUMBER
TWILIO_TO_NUMBERS (comma-separated E.164 numbers, e.g. +15551234567,+15559876543)

In Discord, open a channel's Settings → Integrations → Webhooks → New Webhook. Copy the webhook URL and add it as a Vercel environment variable:

DISCORD_WEBHOOK_URL

The full update payload will be POSTed as JSON to your endpoint. Add these Vercel environment variables:

GENERIC_WEBHOOK_URL
GENERIC_WEBHOOK_SECRET (optional — sent as X-Webhook-Secret header)
