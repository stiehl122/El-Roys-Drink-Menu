# Design References

These docs capture the visual and atmospheric intent for the two restaurants.
They are the first-stop references for any work that touches:

- public page design
- Stitch reviews or handoff prompts
- visual direction
- typography and palette choices
- art direction for imagery, textures, and layout mood

## Shared Rules

- Do not flatten both restaurants into one generic hospitality brand.
- Do not invent a third umbrella brand for the public experience.
- Route-owned pages should lean hard into the assigned restaurant's vibe.
- Shared landing-page work should blend both worlds while keeping each one legible.
- Favor specific atmosphere over generic "modern restaurant website" styling.
- When a task-specific brief calls for existing sign assets, treat that as a hard constraint.
